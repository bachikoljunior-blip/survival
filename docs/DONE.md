## `ALL_DONE` の条件

`docs/STATE.md` に `ALL_DONE` と記載してよいのは、以下を**全て**満たす時のみ（§18 より転記）:

1. 自動検証が全て通る（build / test / Playwright / 分岐走査 / プレースホルダ走査 / コンソールエラー走査 / ライセンス台帳）
2. `docs/reviews/` に Gate D の全項目について証拠付きの批評記録が存在し、未解決の critical / high がゼロ
3. 性能に関する記述が §13 の誠実性要件を満たしている（エミュレーション結果がそう明記され、実機主張がない）
4. `docs/device-test-checklist.md` が存在する

**この4条件を満たさないまま `ALL_DONE` を書くことは、§15 の捏造禁止に対する違反として扱う。**
