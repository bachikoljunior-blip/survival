**このファイルが設計の唯一の情報源である。** README.md は実装者の自己申告文書であり、設計の根拠にしてはならない（§14）。

## 0. §0 既存資産の起点利用 — 何を継承し、何を捨てたか

§0 は、既存実装を起点にする場合、何を継承し何を捨て、なぜそう判断したかをここに記録せよと定める。

### 判断の手続き

既存実装 CINDERLINE を、新規3案と同じ7軸のスコアカードに乗せた（`docs/reviews/gate-a-concepts.md`）。**「既にあるから」を理由に選んでいない。** 31/35 で最高点を取った理由は主に2軸——モバイル実現性と完遂可能なスコープ——であり、この2軸で勝ったのは、他案が**予測**であるのに対し既存実装は**計測されている**ためである。

独創性の軸では既存実装は 3/5 であり、案 C（5/5）に負けている。**この敗北を隠さない。** §5「独創性の所在」は前提ではなく機構と実行に置く（後述 §1）。

### 継承する

| 対象 | 理由 |
|---|---|
| ガスシミュレーションとその4重結合 | プレイヤー・敵・AI経路・視程を同時に支配する。`src/game/ai.js:164-171` で視程が ppm に応じて減衰し、`:302-307` でアーキタイプ別の `gasFear` 閾値による退避が走る。これが「低地へ誘い込む」を実戦術にしている。作り直す理由がない |
| 固定ステップのシミュレーション | `src/core/engine.js:13` で 60Hz 固定、アキュムレータ、最大4サブステップ、バックログ破棄、描画補間 alpha。§12 の要求そのもの |
| ケイパビリティ進行（7種） | `src/game/state.js:25-` 各能力が特定の物語上の出来事で解放され、数値を増やさない。§8 の「数値膨張ではなく戦略を変える進行」を満たしている |
| 物語グラフと `tools/validate.mjs` | フラグを**双方向**に検査する（読まれるが設定されないフラグ＝到達不能分岐、設定されるが読まれないフラグ＝死んだ帰結）。この検査は §6 の帰結要件を機械的に守らせる装置であり、価値が高い |
| 実トリガ経由の通しプレイ harness | フラグを直書きせず実際に遊んで5経路を完走する。§15 の「実際にゲームを動かす」を自動化している |
| 日本語対応と「ゲームロジックは翻訳文字列を見ない」不変条件 | §0 の言語要件を満たす。セーブが言語可搬であることがテストで保証されている |
| 生成アセット方針（画像・音声・モデルのファイルを持たない） | §9 の性能要件と §3 のライセンス要件を同時に解いている。初期ペイロード 1.2MB は §13 の 15MB 上限に対して大きな余裕 |

### 破棄・改修する

| 対象 | 判断 | 理由 |
|---|---|---|
| ビルド系（esbuild + 自作 `build.mjs`） | **改修せず継続。ただし §0 との差異を明記** | §0 は Vite を指定するが、現行は esbuild による自作ビルドで、`base: './'` 相当の相対パス出力と `.nojekyll` 配置という**§0 の実質要件を既に満たしている**。Vite へ移すことは、満たされている要件を満たし直すためだけに全ビルド経路を作り替えることであり、§4「品質基準に達しない機能を再設計する」の対象ではない。**これは §0 からの意図的な逸脱であり、ここに記録する** |
| テスト系（Vitest 不在） | **改修対象** | §0 は Vitest を指定するが、現行にユニットテストの層が無い。通しプレイと静的検証はあるが、§17 が要求する「計算・進行・戦闘規則・資源・クエスト条件・セーブマイグレーション・物語フラグ」のユニットテストが存在しない。**Gate B までに Vitest を導入する** |
| README.md の位置づけ | **降格** | 現状 README が設計文書・計測記録・既知の限界を兼ねている。§14 は批評者が実装者の報告を入力にすることを禁じるため、README を根拠文書として使い続けることはできない。設計の情報源をこのバイブルに移し、README は利用者向けの説明に限定する |
| `docs/` 一式の不在 | **新規作成** | 既存実装は §5・§18・§19 が要求する `bible.md` / `DONE.md` / `STATE.md` / `narrative-state.md` / `assets.md` / `reviews/` を1つも持っていなかった。全て新規作成する |
| 性能検証のシナリオ被覆 | **改修対象** | `tools/perf.mjs` は端末非依存コスト（ドローコール・三角形・CPU・ヒープ）を測るが、§13 が要求する「CPU/GPU スロットリングをかけた、静穏な移動／高密度環境／戦闘／エフェクト過多／UIオーバーレイ／エリア遷移」の6シナリオ計測が無い |
| 未解決の既知欠陥 | **リスク登録簿へ移送** | 後述 §17 |

### スコープを広げない（§0 末尾）

**起点があることを理由にコンテンツを増やさない。** 後述 §16 のスコープ確定数値は、既存実装の実測値をほぼそのまま確定値とし、**上方修正していない**。§4 の削る順序も変えない。

## 1. 創作の柱とアンチ柱

### 柱

1. **空気が地形である。** この街の地図は平面ではなく、高さと風と時刻の関数である。プレイヤーが学ぶのは道順ではなく、どこで息ができるか。
2. **同じ制約が全員にかかる。** 敵の大半も呼吸する。ガスは雰囲気ではなくルールであり、だから低地は危険であると同時に武器になる。
3. **誰も金のために嘘をついていない。** 全員が「誰の生存を数に入れるか」を選んでいる。悪役はいない。
4. **進行とは思い出すことである。** レンは強さを買わない。できることが増える。
5. **ゲームはプレイヤーの答案を採点しない。** 信頼値は道徳メーターではない。告白の上に赤いトーストを出さない。

### アンチ柱（明示的にやらないこと）

1. **陰謀の暴露をクライマックスにしない。** 公社が線を偽ったことは第1章で分かる。主題は「真実は何のためにあるか」であって「真実は何か」ではない。
2. **善悪の二択を出さない。** クライチクの予算と移転スケジュールは実在し、彼の主張は正しいかもしれない。
3. **収集品を置かない。** 拾うものは全て使うものか、読むものか、誰かに渡すものである。
4. **数値インフレをしない。** スキルツリー・レアリティ・レベルを実装しない。
5. **ジャンル慣習で機能を足さない。** 天候・クラフト・拠点開発・評判・乗り物は §7 により任意であり、**採用しない**。
6. **フォトリアルを装わない。** §9 の制約を認め、マテリアル・ライティング・シルエットで戦う。
7. **広さで水増ししない。** 街は1つの連続した地区であり、大都市ではない。

## 2. 前提とテーマ

ホリスは、燃える炭層と80年分の投棄物の上に建つ廃止工業都市である。地下火災は31年燃え続けている。一酸化炭素と黒ダンプが低地に滞留する。屋上・非常階段・渡し板は生き延びられる。街路・地下室・スリップは生き延びられない。**ゲーム内のあらゆる経路判断は、実際には空気についての判断である。**

ホリス復旧公社は火災管理の契約を持ち、四半期ごとに「シンダーライン」——燃焼域の測量境界——を公表する。

22ヶ月前、レナータ・ヴァスコは測量助手だった。Q3 のボーリングデータを読み、公表寸前の境界線が数値の示す位置より 200m 東にあることに気づいた。**何も言わなかった。仕事が必要だったから。**

4ヶ月後——18ヶ月前、ホリスの全員がその夜から数える——公表線が安全と呼んだセラー・ロウの地面が夜に噴出し、9人が地下室で、目覚めないまま死んだ。

彼女は街を出た。戻ってきたのは、死んだ9人の1人イリヤ・ベクが、死の11日前に公社宛てに書き、投函しなかった手紙が届いたからである。手紙には、レンが既に自分で導き出して黙っていたことが、そのまま書かれていた。

### 主題

**真実は何のためにあるのか。**

- レンはそれを**免罪**のために欲しい
- ネッサ・ベクは**正しく悼む**ために要る
- クライチクは実在の予算と実在の移転スケジュールから、**公表は救うより多く殺す**と論じる
- ソルは勤務表とクリップボードから同じ結論に達し、面と向かってそう言う

クライチクとソルは**同じ主張を異なるレジスタで述べる**。台本はこの2人を意図的に引き離して書かれている。ソルは声に出して人数を数え、抽象名詞を一切使わない。クライチクは最も追い詰められた時にちょうど受動態と条項番号に手を伸ばす。

**誰も金のために嘘をついていない。全員が誰の生存を数に入れるかを選んでいる。プレイヤーもそうする。**

### 独自性の所在（Gate A 条件 A2）

**前提は独自ではない。** `docs/reviews/gate-a-concepts.md` §1 に記録したとおり、相互不可視の独立エージェント3体が、既存実装を知らないまま、4案中3案で同じ骨格（高所＝可呼吸の垂直勾配／技術的判断を誤った専門職の帰還）に到達した。これは §1 の固定ブリーフに対する強いアトラクタであり、**明白な答えである。**

独自性は以下の4点にあり、いずれも実装済みで、コードを指して検証できる。

1. **ガスが4つを同時に支配する** — プレイヤー生存 / 敵生存（5アーキタイプ中4が呼吸）/ AI 経路 / 視程。`src/game/ai.js:164-171, 302-307`
2. **進行が数値ではなく能力である** — 7ケイパビリティ、各々が特定の物語上の出来事で解放。`src/game/state.js:25-`
3. **道徳的構造に悪役がいない** — 対立する2人が同じ主張を異なる話し方で述べる
4. **信頼が UI に出ない** — `QUIET` センチネル。`src/content/story.js:51`、抑止は `src/game/director.js:97`

**この4点はいずれも「都市が燃えている」ことに依存していない。**

## 3. プレイヤーの役割と動機

レナータ・ヴァスコ、41歳。19歳で鉱山救護の訓練を受け、救護隊に10年、その後、火を消すはずだった組織の測量技師として8年。**他人が天気を読むように空気を読む。** 何もかもを次の実務的作業に転換して処理する性格で、だから危機の最中には非常に有能で、その後が非常に苦手である。

- **能力**: 空気を読む。ガスの挙動を知っている。高所と換気を知っている
- **限界**: 戦闘者ではない。装甲もない。走れば息が上がり、息が上がれば吸入量が増える
- **内的葛藤**: 免罪を求めているが、免罪を与えられる立場の人間は全員死んでいる
- **続ける理由**: 投函されなかった手紙。彼女が黙ったことを、死んだ本人が書いていた

## 4. 世界設定の歴史と規則

### 歴史

| 時点 | 出来事 |
|---|---|
| 31年前 | 炭層に着火。当初は小規模とされ、封じ込め工事が打ち切られる |
| 以降 | 火災は地下を東進。地表に噴気孔が現れ始める |
| 22ヶ月前 | レンが Q3 ボーリングデータと公表予定線の 200m の齟齬に気づき、黙る |
| 18ヶ月前 | セラー・ロウ噴出。地下室で9人死亡。全員がこの夜から数える |
| 現在 | 街は隔離。残った者は高所と換気を頼りに生きている |

### 世界の規則（例外を作らない）

1. **ガスは低いところに溜まる。** 高さが上がれば濃度が下がる
2. **ガスは源から拡散し、風で流れ、覆いの下に溜まる。** 風は時間とともに向きを変える
3. **呼吸する者は全員この規則に従う。** プレイヤーも、敵も
4. **例外は装備で作る。** ボンベ空気の公社契約業者（WARDEN）だけがガスを無視できる。それは彼らが特権を持っていることの表現である
5. **ガスは動かせる。** ボーリング孔頭を開閉すればガスは別の場所へ行く。**別の場所とは、常に誰かである**

規則5がこのゲームの倫理的中心である。ケイパビリティ `rigVent` の説明文がそれをそのまま述べている:「ガスを別の場所へ移す——そして別の場所とは、常に誰かである。」

## 6. コアループ

1. **空気を読む** — メーターと環境（噴気、陽炎、煤の縞）から、今どこが通れるかを判断する
2. **経路を選ぶ** — 最短は常に最悪。高所を回るか、息を止めて突っ切るか、ガスを動かすか
3. **遭遇する** — 戦うか、避けるか、**低地へ誘い込むか**
4. **持ち帰る** — フィルター、情報、人
5. **選ぶ** — 誰に話すか、誰に渡すか、何を言わないか
6. **街が変わる** — 決定に応じて場所の状態が可視的に変わる

## 7. 戦闘と移動の哲学

**レンは戦闘者ではない。** 戦闘は勝つためのものではなく、**生き延びて先へ進むためのもの**である。

- 逃走は常に有効な戦術である。敵は非常階段と梯子を使わない（**意図的**。屋上はプレイヤーの優位である）
- 走れば呼吸が乱れる。呼吸が乱れれば吸入量が増える
- ガードは奪われない。文脈依存ボタンは独立したスロットを持つ
- パリィは予備動作を読むこと。`coldRead` ケイパビリティは予備動作を1拍早く見せる

### 敵アーキタイプ 5種（§8: HP とダメージの増加は多様性ではない）

| ID | 挙動 | 呼吸 |
|---|---|---|
| SCAV | 日和見。詰めて回り込み、2連撃、不利で離脱 | する |
| BREAKER | 遅い・重装甲・巨大で読める振り。ガードを貫通する | する |
| SLINGER | 距離を保って投げる。棒立ちを罰し、動きを強制する | する |
| WARDEN | 公社契約業者。**ボンベ空気なのでガスが効かない**。マスク着用・支援要請 | しない |
| DOG | 速い。大きく回り込み、直線的に踏み込む。狭所で危険 | する |

**5種中4種が呼吸する。** これが「低地へ誘い込む」を、同じ制約下の相手に対する実戦術にしている。

## 8. 進行と経済

**スキルツリーもレベルもレアリティも無い。** 7つのケイパビリティが、それぞれ特定の diegetic な出来事で解放される。

| ケイパビリティ | 変わること | 解放条件 |
|---|---|---|
| Read the Air | メーターが「どちらへ行けば空気が良くなるか」を示す | 測量マニュアルの回収 |
| Rig a Vent | 孔頭の開閉。**ガスは別の場所へ行き、別の場所とは常に誰かである** | テオに教わる |
| Hard Hands | パリィ受付が広がり、ガードが初撃で崩れない | 圧の下でパリィを成功させる |
| Short Rope | 任意の縁からの制御降下。**下りることが落ちることと別になる** | ソルが自分のロープをくれる |
| Good Habits | 吸収が遅く、排出が速い | 飽和事象を生き延びてなお働く |
| Breach | 板張りの店舗と閉じた地下室が開く | テオがバールを研いでくれる |
| Cold Read | 重攻撃の予備動作が1拍早く見える | ブレイカーに痛い目で教わる |

**経済はフィルターである。** フィルターは通貨であり、命であり、他人に渡せるものである。

## 11. クエストと帰結モデル

分岐は孤立した台詞以上を変える（§6）:

- 信頼関係（追跡され、UI には出ない）
- 得られる助力と敵対
- ミッション経路
- エリアと資源へのアクセス
- 場所の状態（**ジャーナルのテキストではなく、可視的に**）
- 後の対話と振る舞い
- 得られる情報
- エンディングと、そのエピローグビート

**帰結は数章後に届く。** 選択した章の中で完結しない。

`tools/validate.mjs` がフラグを**双方向**に検査する:
- 読まれるが設定されないフラグ = 到達不能な分岐
- 設定されるが読まれないフラグ = **死んだ帰結**。物語が覚えると約束して捨てた行動

**両方ともビルドを失敗させる。** 帰結を持たない選択は、定義により偽の選択である。

## 12. ビジュアル言語

§9 の制約を認める。**フォトリアルなキャラクターモデルは作れない。作れるふりをしない。** 同時に、無加工のプリミティブにも逃げない。

- **ジオメトリよりマテリアル** — 信じられる PBR 応答、一貫した摩耗、正しいスケール、統制されたパレット
- **ライティング階層が最大の武器** — 接地影、AO、意図的に配置された少数のリアルタイムライト
- **シルエットと構図** — 読み取れるランドマーク、明快な見通し
- **手続き的・モジュール的構築** — パラメトリック建築4様式、インスタンス化した瓦礫、テクスチャは実行時に 2D canvas で生成（法線は高さ場からの Sobel、周期的値ノイズでシームレス）
- **パレット** — 炭・灰・錆の暖色と、空の寒色。**空が画面に入る全フレームは寒色を含む**

キャラクターは 20 ボーンのスケルトンにスキンメッシュをロフトしたもの（約950三角形）。顔は作らない。マスクとシルエットで処理する。

## 13. オーディオ言語

**全ての音は WebAudio で合成される。音声ファイルは1つも無い。**

- 打撃音 = ピッチエンベロープ付きのフィルタードノイズバースト
- アンビエンス = リージョンと局所ガス濃度で駆動される多層ピンクノイズ
- 音楽 = 生成的。打鐘音・デチューンドローン・ハンマーパルスの3声が11状態間をクロスフェード
- リバーブ = 生成されたインパルス応答

**モバイルブラウザの音声アンロックはユーザー操作後に行う**（§10）。

## 14. モバイル操作モデル

**最初からタッチで設計する**（§11）。

| 領域 | 割当 |
|---|---|
| 左 約42% | 移動スティック。**触った場所にスティックが出る**（探しに行かなくてよい）。全押しでスプリント |
| 右 約58% | カメラドラッグ |
| 右側タップ | 最寄りへロックオン。再タップで切替。範囲外タップで解除 |
| HIT / HEAVY / ROLL / GUARD | 主要アクション。**入力はバッファされ、硬直中の押下も成立する** |
| USE | 空気が悪ければフィルター、負傷していれば手当 |
| 文脈ボタン | TALK / TAKE / OPEN / READ / CLIMB。**独立スロットを持つ。GUARD は決して奪われない** |
| 空気ゲージ | **タップできない。** 移動スティック領域の内側にあるため、タップ可能にすると移動と競合する（`src/ui/hud.js:78-84` にその判断がコメントとして残されている）。メーターを読む動作は ⌁ ボタンに割り当てる |

設定: 左利きレイアウト、スプリント方式、ガードのホールド/トグル、カメラ感度、ロックオン補助。

**アクセシビリティ**（§11 が列挙する全項目を実装対象とする）: UI テキスト拡大 / 字幕 / 個別音量スライダー / 高コントラスト / 色に依存しない状態表現 / 画面揺れ低減 / ホールドとトグルの選択 / 触覚フィードバック切替。

## 16. スコープ確定数値

**§5 は Gate C の判定がこの数値を参照すると定める。** 以下は既存実装の**実測値**であり、見積もりではない（`npm run validate` の出力）。

| 項目 | 数値 | 根拠 |
|---|---|---|
| エリア数 | 15（屋外リージョン 9 / 屋内 6） | `tools/validate.mjs`: interiors 6、`src/content/world_data.js` の regions 9 |
| クエスト数 | 9（クエストステップ 31） | `tools/validate.mjs`: quests 9 / questSteps 31 |
| エンディング数 | 5（可変エピローグビート 8） | `tools/validate.mjs`: endings 5 / epilogueBeats 8 |
| 敵アーキタイプ数 | 5 | `src/game/ai.js`: scav / breaker / slinger / warden / dog |
| 想定プレイ時間 | 3〜5時間（初回） | **見積もり。未計測。** 根拠は対話 6299 語（読み上げ相当 約40分）＋ 9クエスト/31ステップの移動と戦闘。**Gate C までに通しプレイで実測し、この行を実測値に置き換える** |
| 対話ノード数 | 224（会話 13、総語数 6299） | `tools/validate.mjs`: dialogueNodes 224 / conversations 13 / dialogueWords 6299 |

補助数値: アイテム 11 / ケイパビリティ 7 / 建物 41 / 小物 167 / 構造物 42 / 相互作用 32 / スポーン 27 / フラグ（設定 66・参照 55）。

### この数値は完遂可能か（§5 の要求する自問）

**§5 は「この数値が高品質で完遂できない量なら、今ここで削れ」と定める。**

判定: **削らない。** 理由は、この数値が計画ではなく**既に存在し、5経路の通しプレイで到達可能性が検証されている実測値**だからである。新規に生産すべきコンテンツ量ではなく、既に生産済みの量である。

**したがって本プロジェクトの残作業は、コンテンツ量の追加ではなく、既存コンテンツを §16 の Gate B / C / D の品質基準まで引き上げることである。** この認識をスコープ管理の基本方針とする。

**上方修正を禁じる。** §0 は「起点を活かすことでスコープを広げない」と定める。上の数値を増やす提案は、§4 の削る順序（追加エンディング → 追加地区 → システム的機能 → 敵アーキタイプ数 → クエスト数 → エフェクト密度）を逆行させる提案として扱い、既定で却下する。
