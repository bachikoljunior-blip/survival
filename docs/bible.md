## 0. §0 既存資産の起点利用 — 何を継承し、何を捨てたか

§0 は、既存実装を起点にする場合、何を継承し何を捨て、なぜそう判断したかをここに記録せよと定める。

### 判断の手続き

既存実装 CINDERLINE を、新規3案と同じ7軸のスコアカードに乗せた（`docs/reviews/gate-a-concepts.md`）。**「既にあるから」を理由に選んでいない。** 31/35 で最高点を取った理由は主に2軸——モバイル実現性と完遂可能なスコープ——であり、この2軸で勝ったのは、他案が**予測**であるのに対し既存実装は**計測されている**ためである。

独創性の軸では既存実装は 3/5 であり、案 C（5/5）に負けている。**この敗北を隠さない。** §5「独創性の所在」は前提ではなく機構と実行に置く（後述 §1）。

### 継承する

| 対象 | 理由 |
|---|---|
| ガスシミュレーションとその4重結合 | プレイヤー・敵・AI経路・視程を同時に支配する。`src/game/ai.js:164-171` で視程が ppm に応じて減衰し、`:302-307` でアーキタイプ別の `gasFear` 閾値による退避が走る。これが「低地へ誘い込む」を実戦術にしている。作り直す理由がない |
| 固定ステップのシミュレーション | `src/core/engine.js:13` で 60Hz 固定、アキュムレータ、最大4サブステップ、バックログ破棄、描画補間 alpha。§12 の要求そのもの |

| 物語グラフと `tools/validate.mjs` | フラグを**双方向**に検査する（読まれるが設定されないフラグ＝到達不能分岐、設定されるが読まれないフラグ＝死んだ帰結）。この検査は §6 の帰結要件を機械的に守らせる装置であり、価値が高い |

| 生成アセット方針（画像・音声・モデルのファイルを持たない） | §9 の性能要件と §3 のライセンス要件を同時に解いている。**初期ペイロードの実測値はここに書かない** — 唯一の出所が README.md であり、本文書冒頭で「設計の根拠にしてはならない」と宣言した文書だからである。`shots/` は `.gitignore` されており再現可能な計測成果物がリポジトリに無い。**現状は「未計測」である**（R-19） |

## 1. 創作の柱とアンチ柱

### 柱

1. **空気が地形である。** この街の地図は平面ではなく、高さと風と時刻の関数である。プレイヤーが学ぶのは道順ではなく、どこで息ができるか。
2. **同じ制約が全員にかかる。** 敵の大半も呼吸する。ガスは雰囲気ではなくルールであり、だから低地は危険であると同時に武器になる。
3. **誰も金のために嘘をついていない。** 全員が「誰の生存を数に入れるか」を選んでいる。悪役はいない。
4. **進行とは思い出すことである。** レンは強さを買わない。できることが増える。
5. **ゲームはプレイヤーの答案を採点しない。** 信頼は道徳メーターではない。

   **この柱は現状の実装で守られていない。** 独立批評（`gate-a-narrative.md` N-02）が反証した: 信頼は `src/ui/screens.js:473-487` で5段階の語として常時表示され、信頼変動47件のうち38件が色付きトーストとして可視である。さらに `src/content/story.js:44-50` は「告白の上に『She knows what you are now』という赤いポップアップを出すことは、ゲームが自分の答案に採点することだ」と**出してはならない文字列を名指しで書いているのに、`:479-480` がその文字列そのものを QUIET なしで発火させる**（`src/content/locale/ja/engine.js:60` に翻訳登録済み＝出荷される）。同型が `:426, :890, :1491, :2062` に4件。

   **柱としては維持する。実装がそこに達していないという事実を、柱を下げることで隠さない**（§4「機能一覧を保つためだけに弱い実装を残さない」の逆向きの適用）。修正は IMP-02 として Gate B に起票。

### アンチ柱（明示的にやらないこと）

1. **陰謀の暴露をクライマックスにしない。** 公社が線を偽ったことは第1章で分かる。主題は「真実は何のためにあるか」であって「真実は何か」ではない。
2. **善悪の二択を出さない。** クライチクの予算と移転スケジュールは実在し、彼の主張は正しいかもしれない。
3. **収集品を置かない。** 拾うものは全て使うものか、読むものか、誰かに渡すものである。
4. **数値インフレをしない。** スキルツリー・レアリティ・レベルを実装しない。
5. **ジャンル慣習で機能を足さない。** 天候・クラフト・拠点開発・評判・乗り物は §7 により任意であり、**採用しない**。
6. **フォトリアルを装わない。** §9 の制約を認め、マテリアル・ライティング・シルエットで戦う。
7. **広さで水増ししない。** 街は1つの連続した地区であり、大都市ではない。

## 2. 前提とテーマ

ホリスは、燃える炭層と80年分の投棄物の上に建つ廃止工業都市である。地下火災は31年燃え続けている。一酸化炭素と黒ダンプが低地に滞留する。屋上・非常階段・渡し板は生き延びられる。街路・地下室・スリップは生き延びられない。**ゲーム内のあらゆる経路判断は、実際には空気についての判断である。**

ホリス復旧公社は火災管理の契約を持ち、四半期ごとに「シンダーライン」——燃焼域の測量境界——を公表する。

22ヶ月前、レナータ・ヴァスコは測量助手だった。Q3 のボーリングデータを読み、公表寸前の境界線が数値の示す位置より 200m 東にあることに気づいた。**何も言わなかった。仕事が必要だったから。**

4ヶ月後——18ヶ月前、ホリスの全員がその夜から数える——公表線が安全と呼んだセラー・ロウの地面が夜に噴出し、9人が地下室で、目覚めないまま死んだ。

彼女は街を出た。戻ってきたのは、死んだ9人の1人イリヤ・ベクが、死の11日前に公社宛てに書き、投函しなかった手紙が届いたからである。手紙には、レンが既に自分で導き出して黙っていたことが、そのまま書かれていた。

### 主題

**真実は何のためにあるのか。**

- レンはそれを**免罪**のために欲しい
- ネッサ・ベクは**正しく悼む**ために要る
- クライチクは実在の予算と実在の移転スケジュールから、**公表は救うより多く殺す**と論じる
- ソルは勤務表とクリップボードから同じ結論に達し、面と向かってそう言う

クライチクとソルは**同じ主張を異なるレジスタで述べる**。台本はこの2人を意図的に引き離して書かれている。ソルは声に出して人数を数え、抽象名詞を一切使わない。クライチクは最も追い詰められた時にちょうど受動態と条項番号に手を伸ばす。

**誰も金のために嘘をついていない。全員が誰の生存を数に入れるかを選んでいる。プレイヤーもそうする。**

### 独自性の所在（Gate A 条件 A2）

**前提は独自ではない。** `docs/reviews/gate-a-concepts.md` §1 に記録したとおり、相互不可視の独立エージェント3体が、既存実装を知らないまま、4案中3案で同じ骨格（高所＝可呼吸の垂直勾配／技術的判断を誤った専門職の帰還）に到達した。これは §1 の固定ブリーフに対する強いアトラクタであり、**明白な答えである。**

当初この節は独自性を**4点**挙げていた。独立批評（`gate-a-narrative.md` N-05、`gate-a-scope.md` S-03）が、うち2点を無効と判定した:

- 「進行が数値ではなく能力である」は §8 への**準拠**であって独自性ではない。準拠項目を独自性の柱に数えるのは範疇の誤りである
- 「信頼が UI に出ない」は**反証された**（上記 柱5）

**数を保つために弱い項目を残さない**（§4 の原則を独自性主張にも適用する）。したがって独自性は**2点**である。

### 主柱 — ガスが3つを同時に支配する

プレイヤー生存 / 敵生存（5アーキタイプ中4が呼吸）/ 視程。

| 支配対象 | 実装 | 検証状況 |
|---|---|---|
| プレイヤー生存 | `src/actors/actor.js:608-623`（`lungs.update()` → `harm * GAS_MAX_DPS`）、`src/world/gas.js:36-61`（5定数の設計意図） | 確認済み |
| 敵生存 | 敵も同じ `Actor._update` 経路を通る。`warden` のみ `gasImmune`（`src/game/ai.js:76`） | 確認済み |
| 視程 | `src/game/ai.js:164-170`（ppm 1400 で視程 0.42倍）、`:266-280`（awareness 充填率） | 機構は確認済み。**本編では作用しない**（下記） |

**当初は「4つ」と書き、4つ目に AI 経路を挙げて `ai.js:164-171, 302-307` を引用していた。引用先にその機構は無かった。** 実体は `src/world/nav.js:281-290` の `applyGasCost`（`cost[i] = 1 + clamp01(ppm/900) * 5.5` が A* の辺コスト `nav.js:205` に乗る）だが、**呼び出しは `src/world/city.js:147` の1箇所のみ**で、ワールド生成直後・`gas.time = 0`・`globalScale = 1.0` の初期スナップショットから焼かれたきり再計算されない。

その帰結:

- **`rigVent` で孔頭を開閉しても、敵の経路は変わらない。** §4 規則5「ガスは動かせる。別の場所とは常に誰かである」——本作の倫理的中心——に、敵の経路という帰結が無い
- 風の旋回（プルームを最大 ±9.5m 移流。ナビセルは 1.15m）も、危機の `setIntensity(1.9)` も反映されない
- 逃走は `ai.js:636-642` の局所勾配降下ステアリングでナビを使わない

**AI 経路はガスを読む。ただしそれはゲーム開始時のガスであり、プレイヤーが動かしたガスではない。** 修正は IMP-05 として Gate B に起票。実現すれば主柱は4重に戻る。

**さらに、視程は本編で一度も効かない。** 本編の敵は全員 `src/game/director.js:386-392` で `aggro = true; awareness = 1; aiState = 'combat'` として生成されるため、初回接敵に視程が寄与する場面が無い（IMP-04）。

### 副柱 — 道徳的構造に悪役がいない

誰も金のために嘘をついていない。対立する2人が**同じ主張を異なるレジスタで述べる**。

独立批評はクライチク側を「強く成立」と判定した。追い詰められた瞬間にちょうど受動態と条項番号が出る: `src/content/story.js:1836-1844`（受動態3連＋「clause eleven, if you would like to read it」）、`:1853`（291人という最も痛い数字の直後に「It is recorded, in a file, as an operational efficiency.」）。

ソル側は**部分的に反証された**。「抽象名詞を一切使わない」は事実に反する（`:462, 629, 645, 707, 751`）。また `:707-712` でソル自身が「I'm doing what he does and I'm doing it with my own hands instead of a spreadsheet」と両者の等値を明言するため、「台本は2人を意図的に引き離して書かれている」も正確ではない——**台本は2人を明示的に接続している。**

**「一切」「意図的に引き離す」という強すぎる表現を取り下げ、書き分けの craft が実在することだけを主張する。**

### 最近傍と差分（N-12）

独自性を「前提ではなく機構と実行」へ移した以上、その**実行**を実在作品と突き合わせなければ主張が空になる。

- **舞台の最近傍**: 地下炭層火災で数十年燃え続け放棄された都市は、現実に該当する町が存在する類型であり、それを引いた既存のホラー作品が広く知られている。**差分は超常要素の完全な不在である。** 本作に怪物も異界も無く、危険は一酸化炭素と黒ダンプという実在の気体の物理だけで構成される。ジャンルも異なる（ホラーではなくサバイバル アクションRPG）
- **劇の型の最近垂**: 「数字を知りながら黙った技術職の帰還」＋「予算と条項番号から論じる、悪ではない官僚」という組み合わせは、実在の高評価作品と話法のレベルで近い
- **最も強い差分**: **既存作品の観客が「見る」だけだったものを、本作は「する」に変えている。** プレイヤー自身が `rigVent` でガスを他人の街区へ移す。クライチクが表計算で行う算術を、プレイヤーは自分の手で実行する。ソルが `:707-712` で言う「俺は奴と同じことを自分の手でやっている」は、プレイヤーへの description でもある

### 点火の偶然について（N-11）

物語の点火には4重の偶然が積まれている——ベクがレンと独立に同じ結論に達し、その手紙をテオに託し、そのテオがレンの父を知る人物であり、手紙が1年前に引き払った住所から本人に届いた。

**これを承知のうえで採用している。** 緩和は2箇所で行われている: `src/content/story.js:838-842`（ベクは16年間自分の屋根で雨量計を取っていた＝公表値を疑う人物であることが先に立つ）と、`:1264-1267` のネッサ「everybody knew everybody, which is what people say about a small town like it's charming. **It isn't charming. It means every single one of you had somebody to tell.**」——**偶然を主題側の告発に転化している。**

4つ目（住所）だけが未処理であり、Gate B の修正候補として保持する。

**上記2柱はいずれも「都市が燃えている」ことに依存していない。**

## 3. プレイヤーの役割と動機

レナータ・ヴァスコ、41歳。19歳で鉱山救護の訓練を受け、救護隊に10年、その後、火を消すはずだった組織の測量技師として8年。**他人が天気を読むように空気を読む。** 何もかもを次の実務的作業に転換して処理する性格で、だから危機の最中には非常に有能で、その後が非常に苦手である。

- **能力**: 空気を読む。ガスの挙動を知っている。高所と換気を知っている
- **限界**: 戦闘者ではない。装甲もない。走れば息が上がり、息が上がれば吸入量が増える
- **内的葛藤**: 免罪を求めているが、免罪を与えられる立場の人間は全員死んでいる
- **続ける理由**: 投函されなかった手紙。彼女が黙ったことを、死んだ本人が書いていた

## 4. 世界設定の歴史と規則

### 歴史

| 時点 | 出来事 |
|---|---|
| 31年前 | 炭層に着火。当初は小規模とされ、封じ込め工事が打ち切られる |
| 以降 | 火災は地下を東進。地表に噴気孔が現れ始める |
| 22ヶ月前 | レンが Q3 ボーリングデータと公表予定線の 200m の齟齬に気づき、黙る |
| 18ヶ月前 | セラー・ロウ噴出。地下室で9人死亡。全員がこの夜から数える |
| 現在 | 街は隔離。残った者は高所と換気を頼りに生きている |

### 世界の規則（例外を作らない）

1. **ガスは低いところに溜まる。** 高さが上がれば濃度が下がる
2. **ガスは源から拡散し、風で流れ、覆いの下に溜まる。** 風は時間とともに向きを変える
3. **呼吸する者は全員この規則に従う。** プレイヤーも、敵も
4. **例外は装備で作る。** ボンベ空気の公社契約業者（WARDEN）だけがガスを無視できる。それは彼らが特権を持っていることの表現である
5. **ガスは動かせる。** ボーリング孔頭を開閉すればガスは別の場所へ行く。**別の場所とは、常に誰かである**

規則5がこのゲームの倫理的中心である。ケイパビリティ `rigVent` の説明文がそれをそのまま述べている:「ガスを別の場所へ移す——そして別の場所とは、常に誰かである。」

## 6. コアループ

1. **空気を読む** — メーターと環境（噴気、陽炎、煤の縞）から、今どこが通れるかを判断する
2. **経路を選ぶ** — 最短は常に最悪。高所を回るか、息を止めて突っ切るか、ガスを動かすか
3. **遭遇する** — 戦うか、避けるか、**低地へ誘い込むか**

   **後2者は本編で一度も成立しない。** 本編の敵は全員 `src/game/director.js:386-392` で `aggro = true; awareness = 1` として生成される。加えて本編の敵遭遇は**2回・敵6体のみ**（`spawnEnemy` の呼び出しは `director.js:387` の1箇所、それを呼ぶフックは `:142` と `:145` の2つだけ）で、うち2体はガス免疫の warden である。**ガスで倒せる相手は本編で4体。** 機構は実装済みだが、遭遇設計が一度もそれを要求していない。IMP-04 として Gate B に起票
4. **持ち帰る** — フィルター、情報、人
5. **選ぶ** — 誰に話すか、誰に渡すか、何を言わないか
6. **街が変わる** — 決定に応じて場所の状態が可視的に変わる

## 7. 戦闘と移動の哲学

**レンは戦闘者ではない。** 戦闘は勝つためのものではなく、**生き延びて先へ進むためのもの**である。

- 逃走は常に有効な戦術である。敵は非常階段と梯子を使わない（**意図的**。屋上はプレイヤーの優位である）
- 走れば呼吸が乱れる。呼吸が乱れれば吸入量が増える
- ガードは奪われない。文脈依存ボタンは独立したスロットを持つ
- パリィは予備動作を読むこと。`coldRead` ケイパビリティは予備動作を1拍早く見せる

### 敵アーキタイプ 5種（§8: HP とダメージの増加は多様性ではない）

| ID | 挙動 | 呼吸 | **本編での配置** |
|---|---|---|---|
| SCAV | 日和見。詰めて回り込み、2連撃、不利で離脱 | する | 3体 |
| SLINGER | 距離を保って投げる。棒立ちを罰し、動きを強制する | する | 1体 |
| WARDEN | 公社契約業者。**ボンベ空気なのでガスが効かない**。マスク着用・支援要請 | しない | 2体 |
| BREAKER | 遅い・重装甲・巨大で読める振り。ガードを貫通する | する | **0体（未配置）** |
| DOG | 速い。大きく回り込み、直線的に踏み込む。狭所で危険。`pack` で仲間数に応じ間合いと攻撃性が変化 | する | **0体（未配置）** |

**5種中4種が呼吸する。** これが「低地へ誘い込む」を、同じ制約下の相手に対する実戦術に**しうる**。

**ただし BREAKER と DOG は本編に一度も出現しない**（`gate-a-scope.md` S-01）。挙動の差別化は機構レベルで実装済み（`ranged` / `blockChance 0.68`+`callsForHelp` / `poiseResist`+ガード貫通 / `pack` / `gasImmune`）であり、独立批評も「設計としては §8 を満たしている」と判定した。**問題は差別化の質ではなく、5種のうち2種が配置されていないことである。** IMP-03 として Gate C に起票。

## 8. 進行と経済

**スキルツリーもレベルもレアリティも無い。** 7つのケイパビリティが、それぞれ特定の diegetic な出来事で解放される。

### エンディングがどう決まるか（実装の記述）

**当初この節は「最終メニュー選択ではなく、蓄積された決定と行動によって獲得される」と書いていた。それは事実に反していた**（`gate-a-narrative.md` N-01）。

実装はこうである。`ENDINGS` の `condition` は5件すべてが `{ chose: ['final', X] }` のみ（`src/content/story.js:2260, 2341, 2409, 2461, 2513`）で、`src/game/director.js:1450` が解決する。**どのエンディングになるかは、最終会話の `choose` ノード（`:2170-2192`）のタップ1回で確定する。**

- 蓄積状態で開閉されるのは **5択中2択のみ**: `the cut` は `flag: krajcik_open`（`:2177`）、`everybody out` は `sol_debrief` かつ `trust sol ≥ 16`（`:2185`）
- **`record` / `deal` / `leave` の3つは無条件。** 全員を救い全信頼を積んだプレイヤーが「歩き去る」を選べば `NOTHING OWED` になり、何もしなかったプレイヤーが「記録に載せる」を選べば `ON THE RECORD` になる
- 蓄積は条件付き `beats` と `epilogue.told/untold` で**本文を変える**が、**どのエンディングかは変えない**

**これは `docs/directive.md` §6「それまでの全てを上書きする最終メニュー選択を避ける」に抵触している。** 抵触している事実をここに記録し、Gate C までの修正対象として IMP-01 に起票する。**「蓄積が本文を変えるのだから実質的には獲得されている」という擁護をしない。** §6 が禁じているのは、最終選択が経路を決めてしまう構造そのものである。

## 11. クエストと帰結モデル

分岐は孤立した台詞以上を変える（§6）:

- 信頼関係（追跡され、UI には出ない）
- 得られる助力と敵対
- ミッション経路
- エリアと資源へのアクセス
- 場所の状態（**ジャーナルのテキストではなく、可視的に**）
- 後の対話と振る舞い
- 得られる情報
- エンディングと、そのエピローグビート

**帰結は即時と遅延の両方で届く**（§6 は両方を要求している。当初この節は「選択した章の中で完結しない」と書いており、実装より狭かった）。

- **即時**: `src/game/director.js:158-174` — `shutVents` / `halfVents` が世界のガス源を即座に切り替え、「引きが逆転する。音で分かる」を返す。`src/content/story.js:519-521` — 次にソルに会った時点で `after_shut` / `after_half` / `after_left` に分岐する
- **遅延**: `src/game/director.js:456-492` の `_beginCrisis()` が第2章の `vents_shut` を読み、**第4章の危機が The Stacks で起きるか South Marrow で起きるか**、生存者4人がどこにスポーンするか、どのガス源が動くかを決める。ジャーナルのテキストではなく、遊ぶ側の地形が変わる

**ただし3択の折衷案 `vents_half` は、この最大の帰結地点で `vents_left` に潰れる**（`director.js:462-464` は `vents_shut` の有無しか見ない）。プレイヤーが自ら「両方を少しずつ悪くした」と書いたジャーナル（`story.js:2063-2068`）が、最大の場面でその通りに扱われない。IMP-11 として Gate B に起票。

`tools/validate.mjs` がフラグを**双方向**に検査する:
- 読まれるが設定されないフラグ = 到達不能な分岐
- 設定されるが読まれないフラグ = **死んだ帰結**。物語が覚えると約束して捨てた行動

**両方ともビルドを失敗させる。** 帰結を持たない選択は、定義により偽の選択である。

### この数値は完遂可能か（§5 の要求する自問）

**§5 は「この数値が高品質で完遂できない量なら、今ここで削れ」と定める。**

判定: **削らない。** ただし**当初この判定に付けた根拠は事実に反していた**（`gate-a-scope.md` S-04）。

当初の根拠は「5経路の通しプレイで到達可能性が検証されている」ことだった。その harness の実態はこうである:

| 迂回 | 実装 | 帰結 |
|---|---|---|
| 移動 | `tools/driver.js:41-52` の `goTo` が `p.placeAt(...)` で座標へ**テレポート** | 歩行可能性は未検証 |
| 呼吸 | `tools/driver.js:207` が `G.player.gasImmune = true`（コメント "the harness is testing story reach, not survival"） | **生存可能性は未検証** |
| 戦闘 | `tools/driver.js:168-181` の `clearHostiles` が `e.damage({ amount: 9999 })` と `G.emit('kill', ...)` を直接呼ぶ | 戦闘成立性は未検証 |

**5経路の緑は、物語状態グラフの到達性のみを意味する。** 歩けるか、息ができるか、戦って勝てるかは、一度も検証されていない。**本作の中心的柱「空気が地形である」が、自動検証の対象に一度もなっていない。**

判定を「削らない」に維持する理由は、**コンテンツが既に生産済みであり、新規生産すべき量ではない**ことに限る。到達可能性の検証は根拠に使えない（IMP-06 で実移動の通しプレイを作るまで）。

**したがって本プロジェクトの残作業は、主として既存コンテンツを §16 の Gate B / C / D の品質基準まで引き上げることである。ただし「コンテンツ量の追加は一切不要」ではない** — BREAKER と DOG の遭遇設計（IMP-03）は定義上コンテンツの新規生産であり、これを認めないと Gate C2 を通せない。**当初「残作業はコンテンツ量の追加ではない」と断定していたのは誤りである。**

**上方修正を禁じる。** §0 は「起点を活かすことでスコープを広げない」と定める。上の数値を増やす提案は、§4 の削る順序（追加エンディング → 追加地区 → システム的機能 → 敵アーキタイプ数 → クエスト数 → エフェクト密度）を逆行させる提案として扱い、既定で却下する。
