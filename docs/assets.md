# アセットと依存関係の台帳

`docs/directive.md` §3（独創性と法的安全）および §9（ビジュアル）が要求する記録。

**全ての第三者アセットと依存関係は、出所・ライセンス・URL をここに記録する。** ここに無いものを使用してはならない。追加ライブラリは MIT / Apache / CC0 互換のみ。

最終更新: 2026-07-30 / 対象コミット: Gate A 時点

---

## 1. 実行時に配信されるもの（ビルド成果物 `dist/` に入るもの）

| 名称 | 種別 | ライセンス | 出所 URL | 用途 | 採用理由 |
|---|---|---|---|---|---|
| three.js r0.180 | コード | MIT | https://github.com/mrdoob/three.js | WebGL レンダリング | 唯一の実行時依存。モバイル WebGL1/WebGL2 の両対応、WebGL 1 フォールバック、コンテキストロスト復帰を標準で持つ。自作すると §13 の予算管理に割く時間が消える |

**上記以外に、ビルド成果物へ入る第三者アセットは現在ゼロである。** 画像・フォント・音声・3Dモデルのファイルは1つも同梱していない。

- テクスチャ: 実行時に 2D canvas で生成（`src/render/textures.js`）
- モデル: 実行時にパラメトリック生成（`src/world/buildings.js`, `src/actors/rig.js`）
- 音声: 実行時に WebAudio で合成（`src/audio/audio.js`）。リバーブのインパルス応答も生成
- フォント: **ダウンロードしない。** プラットフォームのシステムフォントスタックのみを使用（日本語は Hiragino Sans / Noto Sans CJK JP / Yu Gothic / Meiryo を CSS で指定）

この方針の帰結として、§13 の「初期ペイロード 15MB以下」は現状 1.2MB 前後で満たされている。**ただしこれは方針の副産物であり、恒久的な保証ではない。** 将来アセットを追加する場合はこの表を先に更新すること。

## 4. 参照資料の扱い（§3）

§3 は、参照を「一般的な品質特性の研究」に限ると定めている。本プロジェクトが依拠している現実世界の事象は以下であり、いずれも**著作物ではなく自然・工学現象そのもの**である。

| 事象 | 種別 | 扱い |
|---|---|---|
| 地下炭層火災（地中火災）と一酸化炭素・黒ダンプの滞留 | 自然・工学現象 | 現象としての機序のみを参照。特定の実在地名・実在人物・実在事故の当事者を作中に登場させない。地名・人物・組織・事件は全て架空 |
| 鉱山救護と可燃性ガス検知の実務 | 職能知識 | 同上 |

**著作権のあるゲーム・映画・ブランドの参照画像をトレース・複製・同梱していない。** 本リポジトリには参照画像そのものが1枚も存在しない（画像ファイルは `tools/vantage.mjs` が生成する自前のスクリーンショットのみで、これは `.gitignore` 済み）。
