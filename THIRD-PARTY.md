## Everything else

All game content — source code, the procedural texture, geometry, animation
and audio generators, the world of Hollis, the story, the characters and
every line of dialogue — is original work created for this project.

No web fonts are loaded. The interface uses the host platform's system font
stack (`-apple-system`, `Segoe UI`, `Roboto`, and monospace equivalents),
which is a reference to fonts already installed on the device, not a
redistribution of them.
